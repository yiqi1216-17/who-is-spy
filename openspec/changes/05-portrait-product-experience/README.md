# 05.0 · Portrait Product Experience

## Outcome

Turn the verified Multi-Agent system into a product people can understand, enjoy, replay, and share: a complete 9:16 first-person game, distinctive evidence-derived Agent characters, event-driven elimination effects, AI theater, spoiler-safe highlights, and post-game omniscient analysis.

## Dependencies

- Change 03 supplies authoritative game rules, public events, Agent identities, strategy provenance, and information projections.
- Change 04 supplies redacted replay, evaluation evidence, failure states, and safe highlight anchors.
- This change cannot make animation, CLI controls, or client state authoritative.

## Artifacts

- `proposal.md` defines the product opportunity and scope.
- `specs/` defines observable portrait, accessibility, view-mode, highlight, and privacy behavior.
- `design.md` records presentation architecture and interaction decisions.
- `tasks.md` is the visual- and E2E-verification checklist.

## Completion gate

The change is ready to archive only after the complete first-person path works at target portrait viewports, critical scenes are CLI-reproducible, reduced-motion and reconnect behavior pass, live spectator secrecy is proven, highlights are evidence-grounded, and post-game omniscient data unlocks only after terminal reveal.
